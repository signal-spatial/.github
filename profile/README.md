## Welcome to the `signal_spatial` Hub

This is the central GitHub space for `signal_spatial`, where we share maps, apps, and open-source code to the greater geospatial community.

Our mission is to:
- Make spatial information easier to understand.
- Create beautiful and actionable static and interactive maps.
- Build clean, reproducible data workflows.

## Our Work

This organization is managed by Colin Stiles. For project questions, open an issue or email [colin@signalspatial.com](mailto:colin@signalspatial.com).

## How to Contribute

We welcome contributions and suggestions! The best way to engage is to open an issue to discuss a bug or new idea.

- 📝 **[Suggest a feature or enhancement](https://github.com/signal-spatial/.github/issues/new?assignees=&labels=enhancement&template=feature_request.yml&title=%5BFeature%5D%3A+)**
- 🐛 **[Report a bug or an error](https://github.com/signal-spatial/.github/issues/new?assignees=&labels=bug&template=bug_report.yml&title=%5BBug%5D%3A+)**

Please review our **[Contributing Guidelines](https://github.com/signal-spatial/.github/blob/main/CONTRIBUTING.md)** before opening a pull request.
